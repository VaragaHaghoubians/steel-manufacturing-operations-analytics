# Sources and attribution

The implemented workflow follows the user-provided manufacturing analytics planning
text. All published records are locally generated synthetic data. None are company data.

Public datasets discussed in the plan are optional future extensions, not inputs here:
- [UCI Steel Plates Faults](https://archive.ics.uci.edu/dataset/198/steel+plates+faults)
  for a separate defect-analysis project.
- [UCI AI4I 2020 Predictive Maintenance](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset)
  for a separate maintenance project.

Follow each source's current license and citation requirements when downloading it.
No public-data or ML result is claimed by this repository.

Publishing guidance follows [GitHub's official local-code guide](https://docs.github.com/en/migrations/importing-source-code/using-the-command-line-to-import-source-code/adding-locally-hosted-code-to-github).
