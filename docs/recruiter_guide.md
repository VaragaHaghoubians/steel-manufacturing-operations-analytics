# Junior portfolio overview

This project demonstrates beginner Python and manufacturing data analysis. It is built
around short scripts and guided notebooks, with synthetic data and clearly explained KPIs.

Suggested CV description, after you understand and can explain the work:

**Steel Manufacturing Operations Analytics | Python, Pandas, Matplotlib**
- Built a practice project with synthetic pressing, welding, machining, inspection and packaging data.
- Calculated production attainment, scrap rate and OEE using Python.
- Created charts to explore downtime, output and possible capacity constraints.
- Documented the findings and limitations in a short management summary.

Put this in Projects, separate from work experience. No real factory improvement or
savings are claimed. Read START_HERE.md and docs/interview_questions.md before presenting it.
