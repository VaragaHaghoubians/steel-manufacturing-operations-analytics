# Optional dashboard extension

The initial project delivers Python analysis and a management PDF, as requested in
the plan. A native Excel or Power BI dashboard is a future extension.

An Excel-ready workbook is included at data/processed/manufacturing_analytics.xlsx.
Import its Clean Data sheet into Excel or Power BI. Filter by date, machine, operation,
shift and product. Display attainment, scrap rate and machine OEE, alongside the loss
Pareto and operation capacity screen. Recalculate ratios from sums when filters change;
never average pre-aggregated OEE percentages. Label all visuals as synthetic and distinguish
process-stage counts from packaged output.
